# Reinforcement

Reinforcement changes the main output when a source-bound check demonstrates a supported defect. Review is optional evidence, not the repair mechanism. The original input and replaced complete output remain recoverable.

The default path starts the preferred eligible translation and independent consultations concurrently. Google, Microsoft and Index are distinct engine families. MyMemory has mixed provenance and supplies fallback, not an independent vote. The official Index Translate 35B-A3B public API requires no user key or local server. It covers 33 exact app identities, excluding Dari. Bing supplies a distinct Dari route; approximations are labelled. English/Persian retains the user-observed Bing preference. All other direction records distinguish coverage, preference and measured evidence; the small reference set does not justify blanket ranking claims.

Completed candidates are checked against the source for exact addresses, identifiers, currency and amount associations, explicit signed quantities, calendar terms, and narrowly verified meaning contrasts. Supported failures can select an entire better candidate. A unique aligned Gregorian month can be repaired from Unicode CLDR, without converting calendars or replacing arbitrary words. Index receives source-derived weekday/month terms and canonical temperature symbols. Unresolved critical details can request a source-bound AI repair, whose result must pass the same selection checks. Custom glossary/context conditions prevent unconstrained replacement.

A uniquely aligned corrupted email, URL or reference can be restored directly from the source when every other protected fact is unchanged. Multiple possible mappings, omissions, additions and ambiguous token boundaries are rejected. These checks run locally after online translation. Index online Oromo→English is excluded because all eight held-out reference outputs remained in Oromo; the other direction remains eligible.

Literal checks do not establish full meaning. Negation, actors, obligation, arithmetic, terminology and implied context can still be wrong. Majority agreement and back translation are not accuracy scores. Small local-model trials found omitted negation, wrong months, changed addresses and copied bad candidates; automatic semantic authority was therefore not granted to those models. Hy and Gemma trials are excluded from the runtime. Index 2B and its local inference runtime were removed in 1.4.1. Online Index repair is separate and remains available.

Each request has a deadline. Failed optional consultation cannot discard a completed primary result; cancellation discards the entire pending turn. Truncated engine responses and partial chunks are rejected. Public quota/challenge responses are treated as unavailable, with cooldowns and no bypass. A turn can still fail when all eligible free routes are unavailable. The app retains the source for retry.

The 1.3 verification directory contains actual full-stack outputs, a held-out human-reference comparison, fresh critical-domain inputs and repair/control experiments. Operational completion, machine lexical similarity and source-detail checks are kept separate. They are not a claim of perfect translation or a native-speaker certification. The dated per-language HTML report gives current evidence and remaining gaps. Earlier research is preserved in verification/previous-1.2.2.

Primary implementation sources: [Index official API](https://github.com/bilibili/Index-Translate/blob/main/inference/llm/call_api.py), [Index models](https://github.com/bilibili/Index-Translate), [Unicode CLDR](https://github.com/unicode-org/cldr-json), [Meta Omnilingual ASR](https://github.com/facebookresearch/omnilingual-asr), [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx).

## Index contingency

When Index fails, eligible Google/Bing candidates still receive the same source checks and narrow deterministic repairs. MyMemory is a reserve with mixed provenance, not an AI reviewer. No successful primary is discarded merely because Index failed. Failed consultation skips a second Index repair request; service/response failures pause new requests for 30 seconds, and 429 uses the bounded quota cooldown. Complete cached results remain available. Failed repairs preserve the earlier result and its warnings. All-provider failure retains the original for retry.

No second keyless AI reviewer is bundled. [Hugging Face inference](https://huggingface.co/docs/inference-providers/pricing) requires a token and limited credits; [Tencent Hunyuan](https://intl.cloud.tencent.com/document/product/1284/77186) uses account billing; [Alibaba translation](https://www.alibabacloud.com/help/en/machine-translation/developer-reference/using-rest-api) requires access keys. These are possible explicit future integrations, not free automatic replacements. Existing user-configured Azure, Google Cloud and DeepL remain translation reserves according to their settings; they are not represented as equivalent AI repair engines.
